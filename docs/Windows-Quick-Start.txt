BUDDY - WINDOWS CURSOR COMPANION

Keep every extracted file together. Run Install-Buddy.cmd to install or
Run-Buddy.cmd to use the portable build. Finish local Ollama setup in Home.
No cloud speech service or API key is needed.

Click the companion for Voice. Right-click for Type, Guide, area selection
and optional tools. Use your configured shortcuts from Settings > Shortcuts;
existing bindings are preserved. Windows+Space belongs to Windows.

Closing Home, or Hide Home - keep Buddy running, leaves the configured
companion and tray service available. Exit Buddy (stops companion) exits.
Reopen Home/Settings from the tray or desktop/Start menu shortcuts.
Buddy.exe --background starts with Home hidden after setup.

REFINE THE ORIGINAL FIELD
Focus a supported AI prompt field before summoning Buddy, then choose
Refine source field; or press Ctrl+Alt+R directly in the field. Review the
anchored diff, Accept or reject, and use Undo within 30 seconds. No prompt
is sent automatically. Changed/expired/unsupported targets are refused.
Refine Buddy draft is explicitly separate and affects Buddy's composer only.

Esc dismisses a review; Ctrl+Alt+Esc stops active Buddy work when available.
Guide points; you click. Optional Agent actions require a reviewed plan and
their applicable separate approvals. Account grants remain disabled.

Read Windows-0.3.9.md for supported fields, privacy limits and remaining
physical microphone/headphone and real-application acceptance checks.
Logs: %LOCALAPPDATA%/Buddy/Logs
