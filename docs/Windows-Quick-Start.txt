BUDDY - WINDOWS CURSOR COMPANION

1. Keep every extracted file together. This folder must contain Buddy.exe.
2. If Buddy is running, choose Quit from its tray menu.
3. Double-click Install-Buddy.cmd. Or use Run-Buddy.cmd without installing.
4. If prompted in Buddy Home, finish PC setup: install/start Ollama and
   download the chat model. No cloud API key is required.

SETTINGS: Double-click Buddy to open Home, even when Buddy is already running.
Use the pinned Settings button or the new Buddy Settings desktop/Start menu shortcut.
The tray and quick chat also have Settings. Portable: Open-Buddy-Settings.cmd.
Only Buddy.exe --background requests startup with Home hidden.

Ctrl + Space          Open the compact chat bar beside your pointer
Ctrl + Shift + Space  Open the separate voice overlay; speak, then pause
Enter                 Send typed text (Shift + Enter adds a line)
Esc                   Stop and dismiss the compact bar
Ctrl + Alt + Esc      Stop listening, generation, guidance and Agent actions

Home > Cursor & shortcuts changes the main shortcut and cursor visibility.
It also enables optional tap-for-chat / hold-to-talk and voice screen context.
Home > Assistant settings enables internet research and Agent mode (off by default).
Focus a tool, summon Buddy, and choose Guide or Agent after entering your task.
Home > Try pointing tutorial opens a harmless practice window.
Agent shows a plan before running and asks approval for each change.
Windows + Space is normally used by Windows to switch keyboard layouts.
Use Home or Buddy's tray icon for models, history, screen context and pairing.

The cursor companion does not replace or move your original pointer.
Microphone and screen input activate only through explicit controls.
Read Buddy-Setup-Guide.md for the full workflow and device requirements.
Read Windows-Assistant-Preview.md for supported actions and current limits.

If launch fails, run Run-Buddy.cmd and inspect:
  %LOCALAPPDATA%\Buddy\Logs

This is a testing build. Native Windows interactions require device testing.
