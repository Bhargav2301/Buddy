# Optional local Piper voice

The owner approved local Piper/VCTK evaluation and integration on 2026-10-03, then explicitly approved updating installed Buddy with the working changes. This optional engine uses `local-voice/runtime/Scripts/python.exe` with the bundled `piper_worker.py`; it is available in an installed package when its approved local runtime and verified model assets are present. It depends on the existing Python 3.12.4 installation on Satonara; this environment is not a portable installer.

Settings > Voice offers Windows and Piper, six VCTK speaker choices plus the selected F3 preset, speaking pace, preview and Stop. The owner selected Voice C (p232) as the default, at the existing Calm pace (-1); Voice B and original F remain available. New Piper preview profiles also select C. The normal installer preserves existing preferences; the authorized local upgrade separately migrated the owner's installed preferences to C and retained a complete pre-upgrade backup. Ordinary builds continue to default to Windows speech because Piper assets are optional. All text/audio processing for synthesis remains local. The sample WAV files contain only the fixed neutral demonstration phrase and are the only generated audio intentionally saved for review.

The choices are A: p226 (95), B: p227 (82), C: p232 (60), D: p225 (107), E: p228 (90), and F: p229 (85), where parentheses give the installed Piper model's explicit speaker IDs. D/E/F are identified as female English speakers from Southern England by the University of Edinburgh's published speaker metadata, rather than inferred from numeric model IDs. The names are matched against the installed, hash-verified model configuration. They use the same existing model, engine and licenses; no extra model download is needed.

The owner selected F3 for addition as an optional preset, without changing default C. `Voice F3 · Light and flowing` stores speaker 85 plus `NeuralPreset: "f3"`. Its fixed audition settings are length_scale 1.55, noise_scale 0.30, noise_w_scale 0.30, 200 ms sentence pauses, and volume 0.90, with no pitch shifting. General pace is disabled for F3 so it cannot silently change the chosen sound. Other voices keep their previous controls and parameters. Switching between F3 and ordinary voices restarts the worker; only F3 uses the audition's ONNX initialization seed 20261003. The first production F3 phrase in a fresh worker matches the approved audition byte-for-byte. Later utterances retain the preset parameters but may vary through the model's stochastic generation. Preset choice is persisted separately from speaker ID; unrecognized names and mismatched speakers fail closed.

The worker uses a CPU-only ONNX session with two compute threads, validates the model and configuration hashes, disables ONNX telemetry and blocks Python socket/subprocess operations. It has no audio output device or network listener. Text goes through standard input, and bounded WAV bytes return through standard output. Private text is absent from command arguments and diagnostic logs. Normal speech is synthesized in memory and is not saved as a file. A 1600-character input limit, 12 MiB output limit and 45-second deadline bound a request.

Buddy owns playback through its existing pinned WASAPI route. Stop, selected-device removal and headphones-only default/property changes cancel active synthesis/playback without another voice/output fallback. Stop terminates the worker process tree; a new explicit request may start a fresh worker. A loaded worker is reused between requests and exits after 60 idle seconds or on disposal. Tests of simulated notifications do not establish physical Bluetooth disconnect latency or whether speakers remain acoustically silent.

The Anaconda installation carries older app-local C++ DLLs. The worker explicitly loads the existing Windows System32 vcruntime140, vcruntime140_1 and msvcp140 libraries before importing ONNX. This is local to the worker process; no DLLs, PATH settings, runtime installations or security settings are replaced.
