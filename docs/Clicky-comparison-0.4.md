# Buddy and Clicky Windows: evidence and implementation status

Compared against Clicky Windows **04f221f91d4750363d7032bcfd355b7dbc5c0e06**. Buddy baseline was **cae3c7d8ac7dfc36fdb188333e0699f244dea5f4 / 0.3.9**; the current source includes the 0.4.0 recognition/refinement batch. This is a source audit with separate test evidence, not a claim that every feature has been accepted in real applications.

**Exactly same** below means the narrowly stated functional contract, never identical code, artwork, visual appearance or performance. **Similar** includes partial support and deliberate privacy differences. **Missing** means the stated capability is absent from the usable product. A fixture pass does not turn an unsupported browser or disconnected provider into a working integration.

## Sequencing and acceptance

Batch 0.4.0 prioritizes local recognition and the demonstrated refinement blocker. The next batch implements bounded same-source lesson follow-ups, explicit selected-window visual input, multiple independently verified drawings and cancellable sentence output. Any saved teaching history must be opt-in, bounded, local and separately clearable; screenshots and incidental source-field text are excluded. Existing capture/approval/three-sentence policies remain in force.

Provider/realtime work follows those local changes. An adapter is only implemented when it parses/validates real protocol shapes with cancellation and bounded mock tests; it is only connected after explicit credential/transmission approval and actual provider acceptance. No paid account, persistent grant, cloud audio or public release is part of this update.

The connected executor exposes no supported browser/computer-control runtime. No alternate automation tool was used to drive third-party applications. The smallest remaining browser check is to focus the real Grok composer, invoke Refine source field, and verify review/Accept/Undo changes only that field without submitting. Unsupported capability refusal is a valid safe result, not a compatibility pass.
