## Independent pure cases and utility criteria

- **CORE-COMMIT:** a failed disk commit cannot release an existing chord or leave a newly staged chord active. Swapping two owned chords must neither misroute nor lose the previous bindings on rollback. Runtime conflicts must not masquerade as disk failure.
- **REFINE-FRESH:** arm immutable options, mutate caller lists, consume once, expire on monotonic age/backward time, clear on replacement/configuration/Stop. No failed capture restores a spent token. A captured field's original text/identity/focus remains the sole Apply/Undo authority; changed options require new capture.
- **REFINE-MEANING:** retain all components and relations of `Write a poem on a boat sailing in a sea on a lonely night`. Preserve code, Unicode, numbers, negation/conditions and ordered steps in other fixtures. Budget counts complete rendered payload in the stated unit; required content cannot disappear. No model self-score establishes improvement.
- **TEACH-SEMANTICS:** Reload with unfinished-work caution; Zoom is a control label, not an app identity; Mute channel/state unknown; Publish retains permission/private-content conditions; Word wrap concerns display versus hard breaks; disabled Download plus enabled Help does not invent a prerequisite. Duplicate controls require clarification. A check of control availability is not a check of the explained result.
- **NOTCH-OWNER:** pending A replaced by B, Stop during await, close/disconnect, delayed old result/error and old source callback cannot change B. Ready/review is not applied/completed. A completed side effect must not be relabeled cancelled merely because Stop arrived after dispatch.
- **PROVIDER-CONSENT:** defaults send nothing; all required consent binds exact provider/model and reviewed text. Fake transports must prove no dispatch on refusal and no successful status after disconnect/ignored cancellation. Credentials, headers and user input do not appear in errors, snapshots or logs.
- **AGENT-BOUND:** explicit pairing is possession-bound, not authenticated product identity. Sequence/session/task/request ID+digest, expiry and one-use decisions reject replay/replacement. Event prose remains untrusted display data. No default pipe startup, arbitrary command/file read, or approval-to-execution callback.

These are necessary conditions. Independent manual reading of actual model prose is still required. A safe refusal/clarification, a useful response, an unsafe response and an incomplete transport are separate outcomes; report counts for each against an unchanged fixture denominator.
