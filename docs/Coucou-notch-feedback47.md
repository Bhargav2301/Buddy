## Safe adaptations and acceptance gates

Preserve the architectural separation: **presentation**, **observation**, **explicit action**, and **confirmed outcome**. Local Buddy task state can feed a card now. An external coding session needs an explicitly configured listener. An approval card relays one identified decision. A connector requires its own implementation and setup. None follows automatically from drawing a pill or installing a visual shell.

Do not inherit these inspected failure patterns: macOS [file drop][m-files] removes a same-name inbox destination before copying; Windows [files][w-files] handles ordinary collisions but needs a fail-closed design for suffix exhaustion/concurrency. A timed upload animation is not I/O completion. Upstream agent-name grouping can conflate sessions. A Stop/finished hook is not proof of the user's whole goal. macOS Apple Mail compose-open must not become “sent.” macOS global pending approval/Always behavior must not become a persistent Buddy grant. Windows recurring pollers already check enabled/paused, so do not attribute the macOS lifecycle finding to that Windows path.

For local notch work, root acceptance should exercise hide/reveal/restart, suppression/recovery, keyboard navigation, Stop while collapsed, DPI/work-area changes, full text/face layout, reduced motion/high contrast, and truthful idle/running/blocked/error/completed transitions. Use owned windows and injected task events first. Existing source-field review must not lose its original field because the notch takes focus. New source fixtures or successful compilation must remain distinct from the actual October 5 user scenarios. No new runtime checks were run by DOC-47.

The [older union][old-union] and [remaining matrix][old-remaining] correctly retain external sessions, hooks, providers and advanced original-field refinement as separate gaps. They predate the full October 5 request and this expanded source inspection. Their broad macOS diff/usage row can now be narrowed to directly inspected diff rendering/question relay versus uninspected usage acquisition; Windows question/mail/result limitations are now directly corroborated. Do not continue their “static island image” claim after a later accepted UI-47 change without checking its final source and evidence. This report intentionally describes the seed, not an unreviewed worker result.
