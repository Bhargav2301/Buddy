No Camera/Spotify activation or actual app-open completion is claimed. A previous user screenshot's precise SSL failure is not reproduced: bounded public web probes pass with normal certificate validation. TLS validation is unchanged.
- New layout/lifecycle/region, screenshot modes, tray/Stop/reopen and competing-shortcut acceptance must run in the announced foreground test window. Physical microphone accuracy, preferred voice quality, headphone disconnect/default-device behavior and real third-party keyboard hooks remain manual acceptance. Fixture results cannot prove them.
