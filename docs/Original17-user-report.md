## Notch and integrations

Newer source adds hover/greeting/return/pin behavior, a task ticker and per-task journal, persistent local notes, local chat with saved conversations and installed-local-model selection, reviewed TXT/MD attachments, and explicitly saved detached placement with return-to-top. Stop cancels pending chat and placement. A text attachment is labelled as file context, not screen capture; completed saved answers may quote it. Task cards require current ownership before reopening their source.

Explicit paired local-agent sessions exchange status/questions over a current-user pipe. Buddy queues an exact reviewed answer or declines; it cannot authorize or execute the originating tool's command. Client identity and completion remain client-reported. No official coding-product adapter, hook installation, usage/diff view or remote dashboard is delivered merely by this broker.

Cloud text sessions support explicit setup, transient credentials, separate exact-message review and disconnect/Stop. They do not automatically receive desktop context, attachments, saved conversations, microphone input or audio. No cloud session was activated here. Gmail/Notion registration/grants, sending/editing dashboards, broad image/PDF inbox, window attachment, wardrobe/seasonal extras, mini-companion groups and Windows media controls remain missing or outside this increment.
