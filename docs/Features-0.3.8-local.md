Small texture differences can be visible when enlarged. Static branding/tray artwork stays original; reduced motion draws the exact original body.

Guide keeps readable lesson sections separate from verified pointers. Later controls remain text until fresh UIA observation identifies them. Actual Notepad/Amoeba acceptance and physical microphone/headphone behavior require user checks; owned-fixture automation is not third-party acceptance. Local speech quality remains limited by the selected offline voice and hardware.

No cloud audio, paid service, account grant, unrestricted shell, repository push or merge is part of this update. Existing voice C/F3, shortcuts, capture protection and user preferences are preserved. Installation includes a full previous application/profile/shortcut backup and a dry-run-verified rollback script.
