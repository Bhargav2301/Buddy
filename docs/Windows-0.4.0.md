# Buddy 0.4.0: broader refinement and local Whisper

Focus the original editable field, then use **Refine source field** or Ctrl+Alt+R. Explicit refinement checks the actual focused field's capabilities instead of requiring its application, window title and field name to match a short list. Supported writable Edit and Document controls can work across applications. Grok/Perplexity/DeepSeek and Codex were also added to the separate, narrow passive-suggestion rules; passive suggestions remain off by default.

Buddy retains the exact HWND, process, runtime field identity, title, bounds and short summon lease. It rejects password/private/hidden fields, terminals, elevated or unsupported targets. Review, Accept and 30-second Undo recheck the same source and exact text. No keyboard paste, clipboard replacement, automatic submission or substitute Buddy composer is used. Only the selected field is subscribed to for text/value changes.

**All applications cannot be guaranteed.** Some browser contenteditable controls expose text reading without a writable Windows accessibility value. Those fields remain safely unsupported. A browser title match alone is not evidence that its composer supports verified replacement. Buddy explains the limitation; the user can explicitly review/copy a draft manually. Actual ChatGPT/Codex success is user-confirmed on 0.3.9. Owned native fixtures cover broader Edit/Document capabilities, guarded Accept/Undo and refusal cases; they do not establish real Comet/Grok compatibility. No supported browser/computer-control runtime was available during this implementation, and no alternate third-party UI automation was used.

[Whisper recognition](Whisper-local.md) is now the local default. Base English was faster and had fewer raw word errors than the tested small models on this PC's synthetic phrases. The microphone/language and model are selectable; Whisper voice requests show an editable transcript for confirmation. C/F3 speech output and existing shortcut/privacy preferences are preserved. Stop ends capture and kills only the owned local inference worker, preventing late recognition from becoming a request.

The next core parity batch covers bounded screen-teaching follow-ups, explicit scoped visual context, multiple independently verified drawings and cancellable sentence speech. Cloud providers and realtime voice remain unavailable pending separately authorized connectivity; interface shapes or mock tests are not connected capabilities.
