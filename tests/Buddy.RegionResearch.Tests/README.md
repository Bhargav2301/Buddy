# Explicit reviewed-query research

`BuddyService.ResearchReviewedRegion(string exactReviewedQuery, CancellationToken ct)` returns a complete `ReviewedRegionResearchResult(Speech, List<SourceLink> Sources)`. The UI must present a blank editable query and require explicit confirmation of the exact outbound text. This method never derives a query from a selected region, screenshot, audio, prior reply, conversation or memory, and none of those are request parameters. WebEnabled is checked before and after asynchronous boundaries. Root owns UI consent, cancellation and source display; this API adds no HTTP endpoint or implicit workflow trigger.

Accepted text contains 1–300 UTF-16 characters, well-formed Unicode and no control/format/line-separator characters. It is passed unchanged to one Web.Search call. Because the existing transport trims and redacts, inputs it would change are rejected for another review rather than silently transformed. This is not a general sensitive-data detector; the user must review the text before external transmission.

Only the first eight search candidates are considered, with at most three unique public HTTPS fetch attempts. Failed attempts count. Search snippets and titles are not evidence. Candidate and final page addresses use the existing public URL policy; the unchanged production WebResearch transport retains TLS verification, DNS/public-address checks, redirect limits, per-fetch deadline and byte cap. No discovered links, model-expanded queries, cookies, screenshots or user credentials are supplied by this API. Tests inject the network transport and do not establish live TLS/DNS/provider acceptance.

Only actually fetched readable pages enter the local model input. At most 4,000 UTF-16 characters per page are supplied as explicitly labelled excerpts, without splitting a surrogate pair. Source links are built by the host from the fetched final URL/title, not from model citations. Truncated source coverage is disclosed in the prompt; excerpts are not proof of full-page context or factual completeness. No usable pages yields a deterministic clarification with no sources and no model invocation.

The selected local Ollama engine receives the exact query and those excerpts only. It gets no saved history, memories, image parameter, search snippets or source URLs. Output must satisfy the ordinary three-sentence ceiling or an explicit tighter limit, plus the existing feature-promotion/source-label gates. A URL-bearing, malformed or overlong summary is repaired once as a complete answer; qualifications are never clipped. A second invalid summary or insufficient evidence produces an honest short clarification. These checks cannot prove semantic accuracy, source credibility or immunity to every prompt-injection wording; factual quality still needs live acceptance.

Host-only `RegionResearchLimits` defaults to five seconds in the inference queue and 60 seconds total, with a maximum allowed total of two minutes. One research request per service is allowed at a time. Stop/StopAll/deadline can return promptly while a task ignores cancellation, but operation ownership remains held until it settles. The core holds the existing shared inference semaphore until its actual engine task settles; a late result cannot publish, retry, persist or start another fetch. An indefinitely stuck underlying task therefore keeps research busy rather than allowing unbounded overlapping calls. This tracks task settlement, not independent confirmation that Ollama GPU computation has stopped after an HTTP cancellation acknowledgement.

No research query, answer or fetched content is persisted or logged. State access reads only the local model name. Root must pass the utterance/request Stop token, display returned sources and use the accepted VOICE-47 sources-attached flag only after those sources are displayed. The API performs no action, app input, native capture, voice-engine selection or speech playback.

```powershell
dotnet run --project tests/Buddy.RegionResearch.Tests -c Release -r win-x64 --self-contained true
```

Focused tests use canned query/page/model content, injected web/model handlers and owned temporary state. They cover exact outbound bytes including the real WebResearch percent-encoding path, disabled/review/length/control gates, fetched-source bounds, no private context/persistence, whole-summary repair, cancellation before/during search/fetch/inference, queue timeout and inference-lease retention through late completion. No actual external website, model, user profile, desktop or audio device is accessed.
